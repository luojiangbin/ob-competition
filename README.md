# Course Context Relay · 课程项目上下文接力

用 [PowerContext](https://github.com/oceanbase/powercontext) 给大学生课设做**跨会话、跨队友、跨工具**的上下文延续。

> 2026 第六届 OceanBase 数据库大赛 · PowerContext 方向 ｜ 队伍 10086

---

## 它解决什么

一门课一个学期，课设做两个月。真实发生的事：

- 上周跟 AI 敲定的架构，这周新开会话，全忘了
- 队友接手，得把"老师的要求、定的选型、踩过的坑"重讲一遍
- 换个工具、换台电脑，上下文带不过去

这个项目把**决策、约束、踩坑**存成结构化记忆，新会话自动召回。

---

## 快速开始

```powershell
# 0. 首次使用先装环境（需要 Python 3.11+，约 3-5 分钟）
.\安装环境.bat

# 1. 启动服务（窗口别关）
.\启动服务.bat

# 2. 灌数据 + 跑实验（另开一个窗口）
.\跑实验.bat
```

服务地址：http://127.0.0.1:8000/docs

## 实验数据

判定方式：`/v1/context/prepare` 返回的上下文是否命中期望关键词——确定性判定，不需要大模型，可当场重跑。

| 组 | 条件 | 准确率 |
|---|---|---|
| A | 自然写法 | 80% |
| B | 写入改写（面向提问） | 100% |
| C | 留出集（10 题，未参与调优） | 100% |
| D | 同义词集（刻意换词） | **10%** |
| E | 同义词集 + 查询改写 | 90% |

D 组是核心发现：**纯字面检索的天花板在语义层**。详细分析见 [docs/实验报告.md](docs/实验报告.md)。

## 技术要点

1. **一门课 = 一个 Scope**，天然隔离，不串数据
2. **记忆写入时改写**：不写"当时的说法"，写"未来会怎么问"（+20pt）
3. **查询时同义词扩展**：深搜→DFS、进程控制块→PCB（同义词集 10%→90%）
4. **确定性评测**：不需要模型 API，结果可复现，答辩可当场重跑
5. **交接不是甩锅**：Handoff 四步流程（契约 → 临时包 → 固化 → 确认回执），交接有边界、有版本、有检查
6. **经验要过审**：Experience 四段式（情境/动作/结果/教训），审核通过才进入召回，不把模型推测当共识

## 环境

- Windows 10/11，Python 3.11+（本项目在 3.14.3 上验证）
- PowerContext 1.4.0，SQLite 存储，Basic memory（无需模型 API）
- 全部依赖装在项目内 `.venv`，不污染系统环境
- 安装脚本默认用清华镜像源；海外网络可把 `-i https://pypi.tuna.tsinghua.edu.cn/simple` 去掉
