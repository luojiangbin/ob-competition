# 上传指南（10 分钟）

> 本地仓库已经建好，两个提交（`b978d65` 项目主体、`932bf7a` 换行符统一）。
> 你只需要在 GitHub 上建一个空仓库，然后把地址填进 `推送.bat`。

---

## 步骤 1：建空仓库（2 分钟）

1. 打开 https://github.com/new
2. Repository name 填 `ob-competition`
3. 选 **Public**（比赛要能公开访问）
4. **不要**勾 "Add a README file"、"Add .gitignore"、"Choose a license"——本地都有了，勾了会冲突
5. 点 Create repository

创建后页面会显示一个地址，形如：

```
https://github.com/你的用户名/ob-competition.git
```

---

## 步骤 2：生成访问令牌（3 分钟）

GitHub 不接受密码推送，必须用 Token。

1. 打开 https://github.com/settings/tokens
2. 点 **Generate new token (classic)**
3. Note 随便填：`ob-competition-push`
4. Expiration 选 **30 days**（够用了）
5. 勾选 **repo**（第一个大项，勾上会全选子项）
6. 拉到底点 **Generate token**
7. **立刻复制**那串 `ghp_...`——刷新页面就再也看不到了

---

## 步骤 3：推送（1 分钟）

双击 `推送.bat`，粘贴仓库地址，回车。

如果提示输入用户名密码：

| 提示 | 填什么 |
|---|---|
| Username | 你的 GitHub 用户名 |
| Password | 刚才复制的 `ghp_...` Token |

看到 `branch 'main' set up to track 'origin/main'` 就成功了。

---

## 常见报错

| 报错 | 原因 | 处理 |
|---|---|---|
| `Authentication failed` | 用了登录密码 | 必须用 Token |
| `remote origin already exists` | 重复添加 | 脚本已处理，会先 remove |
| `rejected (fetch first)` | 建仓库时勾了 README | 删仓库重建，或先 `git pull --rebase` |
| `Permission denied (publickey)` | 用了 SSH 地址 | 换成 `https://` 开头的地址 |
| 中文文件名显示乱码 | 正常现象 | GitHub 网页会正确显示 |

## 备用方案：网页上传（不用命令行）

如果推送怎么都失败：

1. 在 GitHub 新建仓库（同上，Public、不勾任何文件）
2. 点 **uploading an existing file**
3. 把 `ob-competition` 文件夹里的内容拖进去（**不要拖 .venv、tools、data 三个文件夹**，太大）
4. 填提交信息，点 Commit

缺点：没有提交历史，看起来不如 git 提交专业。能用 git 就别用这个。
