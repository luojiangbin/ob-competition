# 场景脚本与评测用例（v1）

> 用途：喂给 PowerContext 的初始数据 + 初赛指标实验的题面。
> 原则：全部取自大二真实课设，不用编造的企业场景。

---

## 一、五个场景（= 五个 Scope）

### S1 数据结构课设 · 迷宫求解

- **约束**
  - 语言 C++17，禁用第三方库（老师明确要求）
  - 必须手写栈和队列，不能用 STL 的 `stack`/`queue`
  - 提交截止 11 月 20 日，需附实验报告
- **已决策**：用 DFS + 回溯，不用 BFS（老师要求体现递归）
- **踩坑**：`vector` 当栈用的时候 `pop_back()` 不返回值，第一版写错导致死循环
- **交接点**：队友接手"把递归改成显式栈"这一步

### S2 数据库课设 · 图书管理系统

- **约束**
  - MySQL 8.0，字符集 `utf8mb4`
  - 必须画 ER 图并做 3NF 分解
  - 不允许用 ORM，手写 SQL
- **已决策**：借阅表用"借阅记录 + 状态字段"，不做软删除
- **踩坑**：外键级联删除把历史借阅记录一起删了，改成 `ON DELETE RESTRICT`
- **交接点**：队友接手"写存储过程和触发器"

### S3 计算机网络实验 · 简易 HTTP 服务器

- **约束**
  - 只能用 socket API，不能用现成 Web 框架
  - 必须支持 GET，能返回 200/404
  - 实验报告要有 Wireshark 抓包截图
- **已决策**：单线程阻塞模型先跑通，再考虑多线程
- **踩坑**：`recv` 没处理粘包，请求头被截断
- **交接点**：队友接手"加并发 + 压力测试"

### S4 操作系统课设 · 进程调度模拟

- **约束**
  - 实现 FCFS、SJF、RR 三种算法
  - 用 C 语言，Linux 环境
  - 输出要含平均周转时间、平均等待时间
- **已决策**：用结构体数组模拟 PCB，不用链表
- **踩坑**：RR 的时间片设为 0 导致死循环
- **交接点**：队友接手"补 SJF 的抢占式版本"

### S5 创新项目 · 校园二手交易小程序

- **约束**
  - 前端微信小程序，后端 Python FastAPI
  - 数据库用学校提供的 MySQL，不能自建
  - 两周内出可演示版本
- **已决策**：先做"发布 + 列表 + 详情"，聊天功能砍掉
- **踩坑**：小程序 request 域名必须 HTTPS 且备案，本地调试要用开发者工具关掉校验
- **交接点**：队友接手"商品图片上传"

## 三、指标怎么算

| 指标 | 计算 |
|---|---|
| 召回准确率 | 命中 `expected_keywords` 全部关键点的题数 / 20 |
| 重复解释次数 | 完成 Q01–Q20 时，需要人工补充说明的次数 |
| token 消耗 | 对照组 vs 实验组的输入 token 总量（脚本统计） |
| 交接耗时 | 从"新会话开始"到"答对第 20 题"的分钟数 |

**对照组（A）**：开新会话，不给任何上下文，人肉复述。
**实验组（B）**：同一 Scope，`PreparedContext` 自动召回。

> 两组必须用**同一批 20 题**、同一台机器、同一天跑，否则数据不可比。
